### В проекте реализован следующий функционал:
#### 1. Согласно ТЗ созданы модели Habit (для привычек) и User (для пользователей).
#### 2. Реализована валидация для модели Habit согласно ТЗ.
#### 3. Для вывода списка привычек реализована пагинация.
#### 4. Настроены права доступа для пользователей по механизму CRUD.
#### 5. Настроены контроллеры и маршрутизация с использованием вьюсетов и дженериков.
#### 6. Реализована работа с отложенными задачами для напоминания о том, в какое время какие привычки необходимо выполнять
#### 7. Настроена интеграция сервиса с мессенджером Телеграм, который будет заниматься рассылкой уведомлений
#### 8. Выполнены настройки CORS, чтобы фронтенд мог подключаться к проекту на развернутом сервере
#### 9. Настроен вывод документации с применением swagger и/или redoc.
